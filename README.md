💻 Frontend - Simulador de Empréstimo

Aplicação React que permite ao usuário simular um empréstimo informando valor, prazo e score. Os dados são validados em tempo real e enviados para a API `/loan/simulate`.

✅ Funcionalidades
- Validação progressiva dos campos (valor → prazo → score)
- Exibição de erros com mensagens e bordas vermelhas
- Resultado da simulação com juros, CET, IOF, total e parcela
- Envio do contrato por e-mail com botão integrado

🛠️ Tecnologias
React · TypeScript · Axios · Vite · API REST
